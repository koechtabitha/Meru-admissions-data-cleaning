Furaha-admissions-data-cleaning
Data cleaning and preparation of Furaha admissions data for analysis.


Project Overview

This project demonstrates the cleaning and preparation of admissions data using Python and pandas.

The original dataset contained 909 records and 94 columns. I filtered the data to focus on the FCME and RI clinic records, standardized important identifying fields, and checked for duplicate registrations.

After removing 2 duplicate records, the final dataset contained 555 unique records.

Data Cleaning Steps

- Loaded the admissions data from an Excel file.
- Filtered records using the AdmissionNumber column.
- Standardized important text fields to uppercase.
- Checked for duplicate registrations.
- Removed 2 duplicate records.
- Exported the cleaned data for further analysis.
